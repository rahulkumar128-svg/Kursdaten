# kursdaten

Taegliche Tageskurse als CSV (Quelle: Yahoo Finance ueber `yfinance`), automatisch per GitHub Actions.
Enthaelt nur oeffentliche Marktdaten, keine Depotdaten.

- Ticker stehen in `tickers.txt`
- Ergebnis: `data/<TICKER>.csv`, Status: `data/_status.json`
- Manuell starten: Reiter **Actions** -> "Kurse aktualisieren" -> **Run workflow**

Keine Anlageberatung. Daten ohne Gewaehr.
